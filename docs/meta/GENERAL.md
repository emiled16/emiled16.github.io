# Execution
In this project, everytime a request is made, create a plan before acting on anything else. Once the plan is ready, present it to me. We will iterate on it until we can come up with something solid. Then you can start executing the necessary steps

# Documentation
Create a maximum of 1 document per task. If you will create a document make it as concise as possible and well structured. Avoid unecessary writing.
Use numbering when you create a document to be able to backtrack the ordering of tasks and history of actions.

## Structure
you have access to 3 main files:
- @docs/meta/GENERAL.md: general rules and info about the project (READ ONLY)
- @docs/meta/NOTES.md: this is a file where you can take notes about important things you discover and that you need to remember for the future.
- @docs/meta/PROGRESS_TRACKER.md: here you can list the tasks that you have or are executing. Any operator, can read this file understand the history of the project (outlines) and understand where to pick up in the current task (if there are any).
